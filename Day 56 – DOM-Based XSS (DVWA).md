Day 56 – DOM-Based XSS (DVWA)

Today I performed DOM-based XSS testing in DVWA at low security level.

Identified a language parameter passed via GET request

Observed direct reflection in the DOM

Confirmed vulnerability using a JavaScript alert payload

Accessed session ID via injected script

Simulated sending the session ID to a local server (lab setup)

Takeaway: DOM-based XSS vulnerabilities can expose session data if inputs are not properly validated on the client side.

Performed in a controlled lab environment for educational purposes.
