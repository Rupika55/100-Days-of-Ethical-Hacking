#100DaysOfEthicalHacking

Today I studied different types of browser storage mechanisms used by modern web applications:

Local Storage

Session Storage

IndexedDB

Cookies

Cache Storage

This topic is important from a security perspective because improper handling of browser storage can lead to:

XSS-based data theft

Session hijacking

Sensitive data exposure

Understanding how data is stored on the client side helps in identifying potential attack surfaces during web application testing.

📌 Key Learning:
Before exploiting a web app, understand where and how it stores data.
